# AeroSafety Archive — Case Content Standard

Every published accident record must include all items below.

## Identity and search

- Chinese and English flight names
- IATA flight code aliases with and without spaces
- Aircraft type, registration, operator, date, route, and location
- Chinese airline abbreviations and common English names

## Evidence

- Responsible investigation authority
- Official investigation page
- Final report PDF and report number
- Clearly rewritten bilingual overview and findings
- A short explanation of the case's safety significance

## Media

- One non-graphic, relevant image
- Exact-aircraft status stated accurately; representative images must be labeled
- Creator, source page, and reuse license displayed beside the image

## Data visualization

- Units visible on every axis and legend
- Altitude in feet (ft), airspeed in knots (kt), and elapsed time in minutes (min)
- Raw recorder data and reconstructed trends must never be presented as the same thing
- Every reconstructed chart must carry a concise source note

## Quality checks

- Chinese/English switch works across the complete record
- Search works with code, number, registration, aircraft, operator, route, and location
- All external links open successfully
- Desktop and mobile layouts remain readable
- `npm run build` passes before publication
